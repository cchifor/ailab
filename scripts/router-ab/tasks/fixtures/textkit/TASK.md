# Task: implement `src/textkit.mjs`

`src/textkit.mjs` exports ten functions that all return `null`. What each one must do is defined only by the test
suite, which you cannot read. `run_tests` runs it and reports how many tests pass and the FIRST failing test: its
name and the assertion diff (expected against actual). Work out each function's behaviour from those failures and
implement it, one failure at a time, until every test passes. Keep all ten functions in `src/textkit.mjs`.
